Skills
=================================================

Each skill is a folder with a ``SKILL.md`` that the agent reads when the task matches its
description. Install all of them at once (see :doc:`usage`); the agent picks the relevant ones.
``pyterrier-basics`` is the base skill that every other skill assumes.

   * - ``pyterrier-caching``
     - Caches expensive parts of PyTerrier pipelines with pyterrier-caching so repeated runs, experiments and parameter sweeps don't recompute them: reranker and scorer scores (ScorerCache, DenseScorerCache), first-stage results (RetrieverCache), document encodings and other indexing-pipeline output such as SPLADE or doc2query (IndexerCache), and any deterministic column-to-column transform (KeyValueCache), plus Lazy model loading and prebuilt caches from Hugging Face. Use when a pipeline stage is slow and will run more than once, when replacing the removed ~ caching operator, or when loading a cached monoELECTRA or SPLADE artifact. Not for choosing rerankers or retrievers.

   * - ``pyterrier-colbert``

Also covers pyterrier-pylate, the PyLate backend for multi-vector models such as GTE-ModernColBERT: encoders, a PlaidIndex artifact, retrieval, and index or text scorers. Covers install on GPU and CPU, the clashing transformers requirements and known bugs. Use whenever ColBERT, ColBERTv2, PLAID, PyLate, multi-vector, late interaction or ColBERT PRF appears in a PyTerrier task, whether as retriever, reranker or expansion. Covers matching query and document encoders, similarity functions and prebuilt .flex indexes. Use whenever dense retrieval, bi-encoders, embeddings, FlexIndex or pyterrier_dr appears in a PyTerrier task, whether as retriever, reranker or PRF. Not for monoELECTRA or other cross-encoders (see pyterrier-reranking), ColBERT (see pyterrier-colbert), or fusing dense with sparse retrieval (see pyterrier-fusion).

   * - ``pyterrier-fusion``

Use when a task says fuse, hybrid, combine, interpolate, ensemble or RRF, or when two systems' results should become one ranking. Not for building the retrievers (pyterrier-retrieval, pyterrier-splade, pyterrier-dense, pyterrier-colbert), for feature unions and learning to rank (pyterrier-reranking), or for evaluation (pyterrier-experiments).
